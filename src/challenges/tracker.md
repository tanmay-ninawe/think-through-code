# Java Daily Challenges — 14-Day Plan

> **Goal:** Build the habit of solving 5 Java problems a day. Notebook first, then code.
> **Streak rule:** Never zero. On bad days, do 1 problem and call it a win.

---

## The Method (read this every day)

For **every** problem, follow these 4 steps in order:

1. **Understand with a tiny example** — Write the input on paper. Solve it by hand.
2. **Find the pattern** — Solve it like a robot would, one tiny step at a time. Write the steps in English.
3. **Translate to Java** — Convert each English step to one line of Java.
4. **Trace before running** — Make a table of every variable after every loop pass. Predict the output. THEN run.

**Rules:**
- Notebook before IDE. Always.
- No AI autocomplete (Copilot OFF).
- No Googling solutions. Only syntax (e.g., "java charAt example").
- Struggle at least 15 minutes before asking for hints.
- Push to GitHub daily. Folder per day: `Day01/`, `Day02/`, etc.
